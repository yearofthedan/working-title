# working-title

A local-first planning and drafting tool for novelists, built on the Snowflake method.

Needs Node.js 24 and pnpm, which [`corepack enable`](https://nodejs.org/api/corepack.html) provides at the version `package.json` names. After cloning, run `pnpm install`, then `pnpm check` to run every local check.

Run `pnpm setup:omp` once per machine. It installs Ponytail, the skill the build work runs under, into your OMP.

How a story is written, agreed and implemented: [docs/dev-flow.md](docs/dev-flow.md).
