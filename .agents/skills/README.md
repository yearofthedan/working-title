# Skills System

The Skills system provides step-by-step "how-to" guides for common development tasks. It ensures that complex procedures are performed consistently and correctly.

## Available Skills

- **[Update Component (TDD)](update-component-tdd.md)** - Workflow for modifying components using Test Driven Development.
- **[Add Feature Module](add-feature-module.md)** - How to create a new, isolated feature module.
- **[Extract Component](extract-component.md)** - Procedure for refactoring large components into smaller ones.
- **[Debug Test Failure](debug-test-failure.md)** - Systematic approach to troubleshooting failing tests.
- **[Create Page Object](create-page-object.md)** - How to build integration test helpers.

## Usage for Agents

1. **When performing a familiar task**: Use the corresponding Skill to ensure you don't miss any steps.
2. **When unsure how to proceed**: Check the Skills list for a relevant guide.
3. **After mastering a new procedure**: If you develop a new repeatable process, document it as a new Skill.
