# Memory System

The Memory system captures project plans, architectural decisions, and technical debt. It helps prevent regressions and ensures consistent implementation of design principles.

## Structure

- **[Plannings](planning/index.md)** - Forward planning, high level backlog, feature plans, technical debt tracking
- **[Decisions](decisions/index.md)** - ADRs (Architectural Decision Records) capturing the "why" behind major choices.
