# 8. Theme outside pieces and stages

Status: Accepted, 2026-10-04

## Context

Snowflake gives no stage for theme, and writers' sense of theme tends to settle late. Options: an early theme stage, theme as a linkable piece, or theme as a project-level element.

## Decision

Theme is one project-level text, editable at any time, shown wherever the writer focuses. It is not a piece, not a stage, and never linked.

## Consequences

No stage asks for a theme before the writer has one. How theme is used to judge scenes is an open question.
