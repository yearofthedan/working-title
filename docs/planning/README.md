# Planning System

The Planning system manages the project's future direction and current tasks. It provides a shared understanding of what needs to be done and how to approach new features.

## Structure

- **[Roadmap](roadmap.md)** - High-level vision and phases.
- **[Backlog](backlog.md)** - Prioritized list of specific tasks and enhancements.
- **[Templates](templates/feature-plan-template.md)** - Standardized format for planning new features.
- **[Active](active/)** - Ephemeral workspace for current implementation plans (ignored by Git except for `.gitkeep`).

## Usage for Agents

1. **When starting a new feature**: Use the [Feature Plan Template](templates/feature-plan-template.md) to create a plan in `active/`.
2. **When looking for work**: Consult the [Backlog](backlog.md).
3. **When discussing direction**: Refer to the [Roadmap](roadmap.md).
