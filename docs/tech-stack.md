# Tech Stack

## Core Technologies

- **Framework:** Vue 3 (Composition API with `<script setup>`)
- **Language:** TypeScript
- **Build Tool:** Vite
- **Package Manager:** pnpm

## Specialized Libraries

- **Graph/Flow Engine:** [Vue Flow](https://vueflow.dev/) (`@vue-flow/core`, `minimap`, `controls`, `background`)
- **Rich Text Editor:** [Tiptap](https://tiptap.dev/) (`@tiptap/vue-3`, `starter-kit`)
- **Utilities:** [VueUse](https://vueuse.org/) (`@vueuse/core`)
- **Layout:** [elkjs](https://github.com/kieler/elkjs) for automatic graph layout
- **Internationalization:** [vue-i18n](https://vue-i18n.intlify.dev/) for UI translations
- **Icons:** [Iconify](https://iconify.design/) with [Phosphor Icons](https://phosphoricons.com/)

## Testing & Quality

- **Unit/Component Testing:** Vitest and Storybook
- **UI Documentation:** Storybook
- **Linting/Formatting:** ESLint, Prettier
- **Pre-commit Hooks:** Husky, lint-staged

## Environment

- **Node Version:** >= 24.0.0
- **pnpm Version:** >= 10.27.0
