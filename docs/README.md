# Project Documentation

Welcome to the project documentation. This documentation is organized using a progressive disclosure model, allowing you to find the information you need at the appropriate level of detail.

## Getting Started

This directory serves as the central hub for all project-related knowledge. Whether you are a new contributor or an AI agent, start here to understand how the project is structured and where to find specific information.

## Context

These documents provide the foundational understanding of the project's purpose, structure, and technology.

- [**Architecture**](architecture.md) - High-level architectural patterns and directory organization.
- [**Domain Concepts**](domain.md) - Core terminology and the application's purpose.
- [**Domain Implementation**](domain-implementation.md) - Technical patterns and methodology-specific implementation details.
- [**Tech Stack**](tech-stack.md) - Overview of the core technologies and specialized libraries used.

## Decisions

We use Architectural Decision Records (ADRs) to document significant choices made during the project's lifecycle.

- [**Decision Records**](decisions/index.md) - Index of all active and archived ADRs.

## Planning

The planning area contains documents related to the project's roadmap and current development focus.

- [**Planning Overview**](planning/) - Access the backlog, roadmap, and active feature plans.

## Guides

How-to references and step-by-step instructions for common development tasks.

- [**Development Guides**](guides/) - Detailed workflows for i18n, icons, component creation, and more.
