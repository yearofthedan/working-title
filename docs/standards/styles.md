# Styles

**Audience:** anyone writing CSS for the app.
**Purpose:** which CSS features a style may rely on.

- **CSS uses only features MDN marks Baseline**, newly or widely available: each feature's MDN page shows its Baseline status at the top ([MDN: Baseline](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)). The app needs desktop Chromium only because the folder mirror uses the File System Access API ([architecture: constraints](../architecture.md#constraints)), and its styles add no second reason.
