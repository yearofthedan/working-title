# Standards

**Audience:** anyone landing a change here, before they have to ask.
**Purpose:** the conventions a change has to satisfy, one page per subject.

What belongs here is a convention on an artefact you read: a commit, a pull request title or body, a file's name, the words in the UI. Each page says what to do, and links whatever backs it up.

What belongs elsewhere:

| It is | It goes in |
| --- | --- |
| How a session behaves — check a claim before asserting it, never edit an agreed issue | `AGENTS.md` and the skills, where it binds without being looked up |
| What a machine enforces — a ruleset, a check | a pointer to it, and the check's own message |

## Pages

- [Communication standards](communication-standards.md): how to write anything at all — directness, placement, living docs and dated records.
- [Commits and merges](commits.md): the issue number on titles and on commits, a pull request and squash only, and the body naming who wrote it.
- [Testing](testing.md): a test beside its code, browser specs in `e2e/`, and what runs each.
